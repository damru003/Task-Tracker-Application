# Task Tracker App

The **Task Tracker App** is a web application designed to help users manage their tasks and projects efficiently. Built using the **MERN stack (MongoDB, Express, React, Node.js)**, this app allows users to track tasks, view project progress, and get detailed analytics for enhanced productivity. It is deployed on **Vercel** for seamless performance and scalability.

---

## Features

- **User Authentication**: Secure login, registration, and password management with JWT-based authentication.
- **Task Management**: Create, update, delete, and view tasks within projects. Tasks can have statuses like "Pending", "In Progress", and "Completed".
- **Project Management**: Create multiple projects with the ability to assign tasks to them.
- **Progress Tracking**: Visual representations of task progress with completion rates and project statuses.
- **Analytics Dashboard**: View analytics with charts and graphs to track task performance and project completion.
- **Responsive Design**: Fully responsive UI built with **Tailwind CSS** for an optimal experience on both desktop and mobile devices.
- **Real-time Notifications**: Instant feedback and notifications using **React Toast** for task updates.

---

## Tech Stack

- **Frontend**: React, Tailwind CSS, Axios, React Router
- **Backend**: Node.js, Express, MongoDB, JWT, bcrypt
- **Deployment**: Vercel (both frontend and backend)
